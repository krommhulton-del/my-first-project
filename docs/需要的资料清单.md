# 东玄卜卦 · 需要收集的资料清单

> 这份清单是给帮忙搜集资料的助手看的。
> **找得到的就发来,找不到的直接跳过,不必勉强、更不要编。**
> 编造的资料比没有资料危害大得多——它会让程序看起来有据,实际上错得理直气壮。

---

## 总的三条铁律(请务必遵守)

1. **每一条都要写来源**:书名+版本/章节,或网页链接。写不出来源的,宁可不给。
2. **不确定就标「存疑」或直接不写**,不要为了凑数补全。
3. **不同来源说法不一致时,把分歧一并列出**,不要自己挑一个当定论。

# 第一优先:穷通宝鉴调候表(最缺、最有用)

这是目前程序最大的知识缺口。现在程序里只有一条粗糙的规则:「冬天生的取火,夏天生的取水」。
真正的表是 **十天干 × 十二个月 = 120 条**,每条指明:该用什么、佐什么、忌什么。

## 要的格式(每条一行)

| 日主 | 月份 | 调候用神 | 佐神 | 忌 | 出处 |
|---|---|---|---|---|---|
| 甲木 | 正月(寅) | 丙 | 癸 | — | 穷通宝鉴·论木 |
| 甲木 | 二月(卯) | 庚 | 丙、丁、戊、己 | — | 同上 |
| …… | | | | | |

**书名**:《穷通宝鉴》,又名《栏江网》《造化元钥》。清代书,公有领域。
常见版本:徐乐吾评注本。

**注意**:这本书原文是按「论木/论火/论土/论金/论水」分章、每章按月份走的。
需要的是**逐条的用神与佐神**,不是整段议论。若只能拿到整段原文,把原文发来也行,我自己整理。

# 第三优先:格局法·八格的成败救应

程序现在只有「扶抑法」(身强用克泄、身弱用生扶),缺「格局法」。

要的是:**正官格、七杀格、正财格、偏财格、正印格、偏印格、食神格、伤官格**,
每一格各自:

- 怎样算**成格**(成立)
- 怎样算**破格**(败)
- 破了之后怎样**救应**

**书名**:《子平真诠》(清·沈孝瞻),徐乐吾评注本最常见。公有领域。

---

# 第四优先:六爻应期细法

程序现在的应期只做了一半(值日、冲空)。完整的应期取法包括:

- **值日**:用神所临之支值日
- **合日**:用神逢合之日
- **冲日**:用神逢冲之日(静者冲之则动)
- **填实**:旬空之爻,逢其本支之日谓之填实
- **出空**:出了本旬
- **墓库**:入墓之爻,逢冲墓之日
- **生旺**:用神逢长生、帝旺之日
- **远近之别**:年月日时各主多远的期

要的是:**什么情况下用哪一种取法**,以及各家的分歧。

**书名**:《增删卜易》(清·野鹤老人)、《卜筮正宗》(清·王洪绪)。公有领域。

# 第五优先:回测语料(名人生辰 + 生平大事)

这个是用来**量准确率**的:程序说某人某年该发生什么,拿他实际发生的事去对。

## 每人要给

1. 姓名
2. **出生日期**(公历年月日;史料若为农历请注明并换算)
3. **出生时辰**:见下方红线
4. 出生地(城市即可)
5. 性别
6. **3–8 件有公开记载的大事**,每件写:年份、什么事、属哪一类、是好事还是坏事
7. 每条的来源

**类别只能从这八个里选**:
`婚恋 / 事业 / 财运 / 学业文书 / 搬迁变动 / 子女 / 健康 / 官司是非`

## 红线:出生时辰不知道就写「不详」

**这条最要紧。**

名人的出生「日期」一般查得到,但「几点出生」几乎都是传闻。
很多命理书里给的时辰,是后人**为了让命盘解释得通而倒推出来的**。
拿这种时辰去验证命理程序,等于拿答案当题目,验了也白验。

所以:

- 只有**正式档案、出生证明、可靠传记明确记载**的时辰才写
- 其余一律写「不详」——写不详我照样能用,只是精度低一点,但结果是真的
- **绝对不要**采用命理书籍里推断出来的时辰

## 优先选谁

- 近现代人物、有正式传记或档案的
- 生平年份争议小的
- 各行各业都要,不要全是同一类人

## 不要什么

- 生卒年有争议的古人
- 只在命理书里出现的「命例」(那是断法的产物,不是独立证据)
- 「某大师断某某」这类二手案例

## 数量

**20–30 人就够起步**,质量远比数量重要。
宁可 10 个来源扎实的,也不要 100 个道听途说的。

# 第六优先:1949 年前中国的时区划分

程序现在给民国时期出生的人做经度校正时,一律按现行东八区算,可能有偏差。

要的是:民国时期中国分为**五个时区**(昆仑、新藏、陇蜀、中原、长白)的
**具体经度界线**与**各自实行的年份**,以及各时区与格林尼治的时差。

来源:民国时期的《中央观象台历书》、或近代计时制度沿革的研究文章。

# 第七优先:高精度节气时刻表

程序自算的节气时刻与公开历书有 **1.5–6 分钟**的误差。
影响面很小(只影响交节前后几分钟出生的人),但能校就校。

要的是:**任意一段年份(比如 1900–2050)的二十四节气精确时刻表**(精确到分,注明时区)。
来源:紫金山天文台历书、香港天文台、或公开的天文年历数据。
