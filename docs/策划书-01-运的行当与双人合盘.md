## 二、一个你没提、但比你说的更严重的真错(已量)

你说「日运里没让用户强调性别」。我去量了,**问题比这句话大得多**。

`dxBirthChart()` 这一行:

```js
return Bazi.chart(dt, gender(ctx || 'q') || '男', lon);
```

用户没填性别时,**程序悄悄按「男」排盘**,而且不说一声。后果实测(368 副盘,1975–2005 逐月取样):

| 量的是什么 | 数 |
|---|---|
| 性别填错 → **大运顺逆翻转** | **100.0%** |
| 性别填错 → 第一步大运干支就不同 | **100.0%** |
| 性别填错 → 喜用五行改变 | 0.0%(喜忌不看性别,这一层没事) |
| 性别填错 → **逐年主事型对不上** | 32.0%(1998 年里 640 年不同) |
| 性别填错 → **人生节点年份对不上** | 34.9%(708 个里 247 个不同) |

**原因**:古法「阳男阴女顺行、阴男阳女逆行」——性别一换,大运方向必翻。
于是大运、流年、年表、问机、择日的「对你」那一层、验盘簿……**全部建在一个可能是错的方向上**。

**这不是「桃花标错了」,是「年表基本是另一个人的」。** 所以档案板块(下面的 A)排在最前面。

## 四、逐板块方案

### 板块 A · 档案簿(v0.83)——**地基,必须最先做**

**现状**:档案簿眼下不是一个板块,是**吉日板块里的一个下拉 + 一个「存档」按钮**。
只能存和切,**不能删、不能改名、不能编辑**;存的字段是 `{id, name, date, time, gender, place}`。

**要做的**:

1. **独立板块**(`sec-dangan`,id 前缀 `da-`),从专项菜单进。列表式:
   每份档案一行 —— 名字、生日、时辰、性别、出生地,右侧「用这份」「改」「删」。
2. **新建 / 编辑 / 删除 / 复制**齐全。删除要二次确认(误删就没了,本机存储没有回收站)。
3. **性别改成必填**,并且**去掉那个悄悄默认「男」**:
   - `dxBirthChart` 拿不到性别时**返回 null 并明说**,不许自作主张排一副盘;
   - 界面上给一句人话:「性别不填不行——古法男女的大运方向是反的,填错等于看的是别人的命」;
   - 已有档案里性别为空的,进板块时挑出来让用户补。
4. **每份档案带一个「这份档案准不准」的小结**:钟点填没填、`Dingshi.stability` 的档位。
   不填钟点的,当面写「这份档案的喜忌有 67.7% 的概率是掷出来的」(§八 的数)。
5. **验盘簿跟着走**:`yanpan.js` 的记录是按生辰指纹存的,换档案自动换簿子——这条已经成立,只需接上界面。

**口径归属(§四)**:档案簿只管**存取**,一个断法都不许自己算。

**验收**:
- 单测:增删改查的边界(重名、空字段、删掉当前选中的那份、导入导出);
- **e2e:性别为空时,`dxBirthChart` 必须返回 null,且界面给出提示——不许悄悄按男排**;
- **回归测**:补上性别之后,年表节点与补之前必须不同(证明这个洞是真的堵上了)。

### 板块 A′ · 年龄改具体岁数(与 A 同版发)

**现状**:5 处 `<select>` 用区间(`18以下 / 18-25 / 26-30 / …/ 60以上`),
在 `index.html` 的 803、831、1038、1069、1309 行。

**改法**:
- 有生日的**根本不该问年龄**——直接从生日算,并显示「按你档案里的生日,今年 34 岁」;
- 没生日、或替人问的,给一个 0–120 的数字输入(不是下拉,下拉 120 项没法用);
- 「不想透露」保留(那是隐私选项,不是精度问题);
- `ageLabel()` 与 `qAge()` 两处折算跟着改,**折法只许有一处**(§四)。

**为什么这条值得做**:`dashi.js` 的年龄闸门(`AGE_GATE`)是按具体岁数判的
(姻缘 16 岁起、子女 20 岁起),喂一个「26-30」进去,程序内部还得挑一个数——
**那个挑法现在是隐式的**,等于替用户做了个他不知道的假设。这与 v0.75 修时辰折法是同一类问题。

**验收**:五处入口统一;折法只此一处并钉结构测试;有生日时不再问年龄的 e2e。

### 板块 B · 双人合盘 · 中式(v0.84)——**你最想要的那个**

**新模块 `hepan.js`。** 输入两副盘(从档案簿选),输出**五层**,层层摊开给人看:

| 层 | 断什么 | 元素出处 | 组合规则的出处 |
|---|---|---|---|
| ① **旺不旺我** | 他的日主五行,落在我的喜用里还是忌神里 | 喜忌有出处(扶抑法) | **自拟** |
| ② **我旺不旺他** | 反过来算一遍——**这一层必须双向报**,不许只报一边 | 同上 | **自拟** |
| ③ **两盘的冲合** | 日柱天克地冲、日支六合/三合/相刑/相害 | 冲合刑害逐条有原文 | **自拟** |
| ④ **补不补得上** | 我缺的那一味(调候/最弱五行),他身上有没有 | 调候有《穷通宝鉴》逐格 | **自拟** |
| ⑤ **同期走什么运** | 未来十年两人的年表叠在一起:哪几年一个上一个下 | `dashi.js` 现成 | **自拟** |

**四种关系分别给结论**:恋爱 / 合作 / 朋友 / 共事(上下级)。
——**不是一个总分**。同一对人,合作可能极好、婚姻可能极糟(①②不对称就是这种情形)。
给一个总分是最偷懒也最容易骗人的做法,不做。

**必须守住的三条**:

1. **诚实分级要比现有板块更低,而且写在第一屏**:
   「元素每一条都有古书撑着,但**「两个人合着看」这套算法是我自拟的,一件回测都没有**。
   它说得通,不代表它验过准。」
2. **不许给「不合适、别在一起」这种断语。** 铁律一(零说教)+ 铁律五(不推荐花钱消灾)之外,
   这里要再加一条自律:**合盘只报「哪一层顺、哪一层拧」与「拧在哪、怎么绕」,不替人做去留的决定。**
   这一条要写进 §二 铁律。
3. **姻缘方向那条铁律照旧管用**(v0.77):合盘不许自己补一个「你俩这年感情大吉」。

**验收**:
- 单测:①②的对称性检查(A 对 B 与 B 对 A 是两个不同的数,不许算成一个);
  四种关系的结论不许恒同(否则那四个分类是摆设);死条穷举(哪一层的哪个判语永不触发);
- **说人话**:全部界面字段过 `tijian.js`,一个术语不许有;
- **诚实**:界面第一屏必须出现「自拟」「没有回测」字样,钉成测试。

### 板块 D · 改运 ·「运的行当」(v0.86–0.87)

这是你要的**主菜**,也是最容易做成鸡汤的一块。所以先把**不做什么**写死:

**绝对不做**:
- ❌ 不推荐任何花钱的东西(铁律五)——开光、法物、改名收费、风水摆件,一概不提;
- ❌ 不讲道理、不谈心态修养、不写「你要相信自己」(铁律一)。
  你提到「心态、认知」——**这一层我只做「具体动作」,不做「道理」**。
  例:不写「保持积极心态」,写「这三年别自己扛,每月固定找一个说得上话的人聊一次」。
- ❌ 不承诺「照做就能改运」。

**做什么**:把**已经算出来的东西**串成一份**可执行的清单**,并标出每一条的分量。

结构:**一个诊断 + 六条可动的杠杆**

```
诊断:你眼下这十年走的是什么路数、卡在哪一味上(取自 bazi 的喜忌与调候)

杠杆一 · 地   去哪、避哪          ← dili.js 七层(已有)
杠杆二 · 时   哪几年动、哪几月办   ← dashi.js 年表 + jiri.js 择日(已有)
杠杆三 · 色   穿用什么颜色         ← bazi 喜用(已有,现在散在各处)
杠杆四 · 业   吃哪一路的饭         ← dili 的「业」层(已有,要扩)
杠杆五 · 宅   住处怎么调           ← 板块 C 的占宅(新)
杠杆六 · 人   身边该多走动谁       ← 板块 B 的合盘(新)
```

**关键设计:每条杠杆要标「这一条能顶多少」**,而不是罗列一堆建议。
——因为**这六条的分量本来就不一样**,不标分量就是耍流氓。分量怎么定?
**照实说:目前没有任何回测支撑,分量只能按「这一层在程序里的证据强度」排,并当面写明这是排序不是疗效。**

**这一块的诚实分级是全项目最低的**,必须写死:
> 「这六条里,**地、时、色、业**是从你的盘算出来的,有据可依;
> **宅**要另起一卦;**人**是自拟的算法。
> 但没有一条验过『照做之后运真的变好了』——那需要一份『某人做了某事之后过得如何』的语料,眼下没有。
> **所以这一页给的是依据,不是疗效。**」

**验收**:六条杠杆全部取自已有模块,`zhuanyun` 板块**不许自己算任何断法**(§四);
全部文案过体检员;界面必须出现「不是疗效」那段话,钉成测试;
**死条穷举**:六条杠杆在各种盘下都触发得到,没有永远不出现的那一条。

### 板块 E · 西洋合盘(v0.88 起,工程量最大)

**能做,但要先把地基打对。** 分两层,分开说:

- **排盘层(可以说准)**:行星黄经用 VSOP87 截断级数自算,精度可到角秒级;
  宫位制(Placidus / Whole Sign)、相位与容许度都是有公开标准的现代约定,可逐条对公开星历核验。
  **这一层和节气时刻是同一类东西——有客观标准、可外部对照、可以说准。**
- **断法层(只能说通行口径)**:「日月相刑代表什么」这类释义没有中文古籍,
  是现代西方占星的通行说法。**必须标明来源性质,不许挂古书。**

**为什么排在最后**:自建星历是这份策划书里唯一一件「纯工程量」的活(十颗行星 × 数百项级数),
而且它对现有任何板块都没有依赖关系——随时可做,不必卡在前面。

**先做一件小的探路**:只做太阳、月亮、水金火五星的黄经 + 合冲刑拱四个主相位,
拿三个已知生日对公开星历核对,误差压到 1 角分以内再往下走。**核不过就不往下做。**
