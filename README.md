# 东玄卜卦 · 三钱起卦程序(内测 v0.4)

以《周易》六十四卦体系为本的卜卦网页程序:掷币、起卦、纳甲排盘、解读、AI 深断、存档一体,纯静态、手机可安装为应用(PWA)。

## 功能

- **三钱法起卦**:每掷三枚铜钱(字=3,背=2),和为 6 老阴×/7 少阳/8 少阴/9 老阳○,六掷自下而上排爻。支持逐爻掷与一键成卦。
- **绝对随机**:每枚铜钱一比特,取自 `crypto.getRandomValues`(密码学安全随机源),无模偏差;分布经 4 万爻统计检验(6:7:8:9 ≈ 12.5%:37.5%:37.5%:12.5%)。
- **解读一体**:按解卦优先级自动取材——静卦用本卦卦辞;一爻动以动爻爻辞为核心;二三爻动本变并重;四五爻动以变卦为主;六爻全变用变卦卦辞(乾坤全变分别用用九/用六)。附大象、小象、东玄白话断语与吉凶评级、八卦类象方位、先后天数与地支应期参考。
- **纳甲排盘(京房法)**:八宫归宫与世应、纳甲干支、六亲、六神、月建日辰、旬空,全套自动装卦。干支历法自实现:日柱以 2000-01-07 甲子日为锚(零点换日),月建与年柱以节气为界(太阳黄经 Meeus 算法,立春 315° 起寅月)。
- **东玄深断(AI 细批)**:一键把本卦卦象、排盘、经文取材连同所问之事发给 Claude 模型(Claude:`claude-fable-5` 顶配、`claude-opus-4-8`;DeepSeek:`deepseek-reasoner`、`deepseek-chat`,DS 通道附加断卦流程与输出红线的专门调教),按「东玄」铁律流式生成针对所问之事的深度断语,存入卦档。需自备 Anthropic API Key(仅存本机浏览器,直连官方接口;Fable 5 按官方建议自动带 Opus 4.8 服务端兜底回退)。
- **卦象回报**:一键复制标准格式的【东玄掷卦 · 卦象回报】+ 纳甲排盘文本,发给卦师细断。
- **卦档(历史记录)**:每卦自动存入浏览器 localStorage(仅本机),AI 深断一并归档,可展开回看、单条删除、整档清空、导出 JSON。

## 使用

直接用浏览器打开 `index.html`,或起个静态服务:

```bash
python3 -m http.server 8000   # 然后访问 http://localhost:8000
```

## 手机上使用

**方式一:即开即用(推荐先试)**
打开 Artifact 版链接即可在手机浏览器直接用(单文件版,卦档存于手机浏览器本机):
<https://claude.ai/code/artifact/e35dca3b-889f-4126-9df6-b9eb80e44de9>

**方式二:安装为手机应用(PWA,离线可用)**
1. 把本仓库部署到任意 HTTPS 静态托管。最简单是 GitHub Pages:仓库 **Settings → Pages → Deploy from a branch**,选定分支与 `/ (root)` 目录,保存后得到 `https://<用户名>.github.io/<仓库名>/`;
2. 手机浏览器打开该地址:
   - **iPhone(Safari)**:分享按钮 → 「添加到主屏幕」;
   - **Android(Chrome)**:右上菜单 → 「安装应用 / 添加到主屏幕」;
3. 之后从主屏幕图标进入,全屏无地址栏,断网也能起卦(Service Worker 已预缓存全部资源),卦档存在本机。

## 内测

```bash
npm test       # 核心 24 项 + 纳甲 14 项:数据完整性/掷币数学/变卦推导/解卦优先级/八宫世应/纳甲六亲/干支历/旬空/六神/随机分布
npm install    # 装 playwright-core 后:
npm run e2e    # 浏览器端到端 11 项:成卦流程/回报格式/排盘渲染/AI 区交互/卦档持久化与增删
```

**AI 深断说明**:在 [platform.claude.com](https://platform.claude.com) 的 Console 创建 API Key,在应用内「设置 API Key」处填入。Key 只存于本机浏览器 localStorage;深断请求(卦象 + 排盘 + 所问之事)直连 `api.anthropic.com`,按 token 计费。Artifact 托管版因内容安全策略禁止外联,深断请在 PWA/本地版使用,或复制回报文本粘给对话中的东玄。
