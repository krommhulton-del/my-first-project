# 网页 pre-vis — v4 (cinematic)

一个**单文件、自播放的网页交互短片**。不是 PPT，不是游戏 HUD —— 是一段"被载入又被清除"的人生切片，按电影的方式放映。

> 打开方式：用手机浏览器打开 `index.html`，**竖屏 + 耳机**最佳。点按任意处进入，之后它会自己往下放；想快进就点画面，想回看就划出底部进度条跳帧。

---

## 这一版到底改了什么（相对 v3 "像 PPT"）

v3 是一帧帧静态图 + 文字。v4 把"静帧"换成了"会呼吸的镜头"，技术含量都在看不见的地方：

| 维度 | 做法 |
|---|---|
| **氛围全部 Canvas 实时生成** | 没有一张背景图是死的：天桥的**长曝光车流光带**、俯瞰夜景的**万家灯火 bokeh**、片场的**钨丝光锥 + 浮尘**、CBD 的**玻璃幕墙光柱**、龙舌兰**杯底倒影**、出租车窗外**散焦霓虹流光**——逐帧算出来的。 |
| **程序化配乐（WebAudio）** | 无音频文件：低频 drone 和弦 + 空气噪 + 反馈延迟造空间感；过场有涌动，结尾有一记低频重击，打字机有滴答。可一键静音。 |
| **景深 / 视差** | 指针或手机陀螺仪驱动，画面有前后层次，人物"被环境压住"。 |
| **胶片质感** | 实时颗粒 + 暗角 + 偶发竖划痕 + 极轻的"片门微颤"，宽银幕黑边压上去——放映机的味道。 |
| **排印即镜头语言** | 旁白像字幕一样逐行浮入；金句（卸妆棉 / 良辰美景奈何天 / 两不相欠）当**标题卡**处理；古典句**竖排**。 |
| **结尾"无相"是真的湮灭** | "[ 数据已清除 ]"之后，屏上的字**逐字打散、模糊、飞散**，画面擦黑——记忆被抹去——再浮出落款联。 |
| **轻互动** | 帧05 触碰画面把"愿望"放在桥上（光点绽开→模糊被车流带走）；帧08 四选一，选项决定帧09"那个人"的旁白。 |

## 现在是占位、之后换真图的地方

- **人物（立绘）**：当前是抽象的"暖光存在"——一团有位置、有冷暖、会轻浮动的光，守住"女主不正脸 / 男主只露手"的铁律，也避开了 v3 的"大头照怼脸"。
- **换图很简单**：每个镜头的 `#presence` 是一个独立图层，MJ 真图回流后把它换成 `<img>`（或叠在 Canvas 氛围之上）即可，氛围层不用动。帧09 真图须**只露手 / 腕表**。

## 控制
- 点按任意处：进入 / 快进到下一镜
- 底部（划一下唤出）：播放·暂停 / 帧进度条（可点击跳帧）/ 静音
- 键盘：`Enter` 或 `空格` 进入，`→` 下一镜
