# 《纸上花火》答辩 PPT · 逐页内容 + 讲稿
### 策划课大作业 · 答辩用

> 用法：照此做 14 页 PPT（每页：标题 + 要点 + 配图）。每页下面的「🎤讲稿」就是你站着念的话，约 6–8 分钟讲完。配图用 `效果图/` 里的概念图。

---

### P1 · 封面
- **纸上花火 · Paper Fireworks**
- 副标题：一台走得进去的青春时光机 · 古早怀旧主题 VR 体验
- 配图：关键视觉（黄昏少女卧室）
- 🎤讲稿：「大家好，我的策划是《纸上花火》。一句话——戴上头显，回到我们 QQ 空间、花火杂志的那个夏天。」

### P2 · 一句话概念
- 戴上头显，回到 2005–2012 那个 QQ 空间、非主流、花火杂志的年代，在一间被时光封存的少女卧室里，翻动每一件旧物，唤醒一段记忆，完成一次对青春的温柔告别。
- 🎤：「它不是一个要赢的游戏，是一座可以走进去的、属于一代人的记忆博物馆。」

### P3 · 为什么做它（立意）
- 母题：**美好转瞬即逝；每个人的青春都值得被温柔收藏一次。**
- 情绪关键词：怀旧 · 治愈 · 沉浸 · 温柔的告别
- 🎤：「怀旧是这几年最强的情绪。但市面上多是图片和短视频，没人让你真正'走回去'。VR 能做到——这就是我的切入点。」

### P4 · 目标用户与市场
- 核心：90/95 后（QQ 空间原住民）；扩展：Y2K 美学党、治愈体验玩家
- 场景：个人头显 / 线下怀旧快闪展览 / 品牌联名（汽水·文具·音乐 App）
- 🎤：「这群人正是消费主力，又最吃怀旧。线下展览和联名是它天然的商业出口。」

### P5 · 世界观与场景
- 一间 12㎡ 千禧少女卧室：碎花床、海报墙、CRT 电脑 + QQ、卡带机、梳妆台、铁皮文具盒、相片墙、窗外黄昏蝉鸣
- 配图：卧室全景概念图
- 🎤：「我用'道具密度'而不是'场景大小'堆沉浸感——一进门，你就该脱口而出：这就是我那时候的房间。」

### P6 · 核心玩法
- 第一人称 VR 漫游 + 手柄交互；**唤醒旧物 → 收集记忆碎片 → 集齐解锁结局**
- 无失败、无倒计时、治愈向
- 🎤：「玩法很轻：自由地翻、看、听。每唤醒一件旧物，得到一片记忆。」

### P7 · 亮点：会说话的旧物（互动清单）
- 台式机→QQ 空间｜卡带机→那年的歌｜杂志→竖排言情｜同学录→毕业留言｜拍立得→拍照留念｜信纸→**写一封寄不出的信**
- 配图：QQ 空间界面 + 杂志翻页概念图
- 🎤：「每一件旧物都是一段记忆的钥匙。重点说两个：开机进 QQ 空间，闪图、非主流签名、自动播放的空间音乐全回来了；还有'写一封寄不出的信'——」

### P8 · 情感仪式（让怀旧变成参与）
- ① 写一封寄不出的信 → 信化作光飘出窗外｜② 拍立得留念 → 贴上相片墙
- 配图：写信（信化作光）概念图
- 🎤：「光看会腻，所以我设计了两个主动仪式。写信，是把没说出口的话交给那个夏天；它不会寄出，但你放下了。」

### P9 · 美术风格
- 千禧 Y2K × 古早言情 × 非主流；暖黄夕照 + 玫红网格 + 衬线竖排
- 电影级怀旧后处理：暖调 + 暗角 + 胶片颗粒 + 泛黄，把"塑料 3D"压成"旧照片"
- 配图：风格拼贴 / 调色对比
- 🎤：「美术是这个产品的命门。我用后处理把画面压成一张会动的旧照片——这是它和普通 3D 场景最大的区别。」

### P10 · 技术方案
- Unity + URP（Bloom/调色/颗粒/暗角）；**XR Interaction Toolkit**（手柄射线+抓取）；TextMeshPro 竖排
- UI 两模式：**Overlay**（系统/进度/相册）+ **WorldSpace**（QQ 空间/杂志贴在物体上）
- 防眩晕：瞬移 + 舒适转向 + 暗角；可出桌面演示版
- 🎤：「技术上用主流 VR 管线，UI 两种模式都用上，专门做了防眩晕。」

### P11 · 叙事流程
- 黄昏入场 → 探索唤醒 → 集齐记忆（推到入夜）→ 写信 → 拍照 → **房间褪色光化、旧物飘散** → 落款金句
- 配图：褪色光化结局概念图
- 🎤：「结尾我让整个房间在夕阳里慢慢褪色、化成光飘散——美好转瞬即逝，你完成了对青春的告别。」

### P12 · 音乐与音效
- 原创年代感主题曲（钢琴+卡带底噪）+ 环境音（蝉鸣/电扇/拨号/QQ 提示音）
- **全部原创或免版税，规避版权**
- 🎤：「声音是怀旧的另一半。年代金曲我用原创致敬版，规避版权，又保留那个味道。」

### P13 · 商业与展览价值
- 怀旧 = 强情绪流量；每帧可截图传播；适配线下快闪展览 + 品牌联名；长尾话题强
- 🎤：「它不止是作业：怀旧自带传播力，线下展览和联名是清晰的落地路径。」

### P14 · 结语
- 「**那年夏天，我们都以为来日方长。**」
- 纸上花火 · 谢谢观看
- 🎤：「《纸上花火》——把一代人的青春，温柔地收藏一次。谢谢大家。」

## 答辩问答预案（老师可能问）
- **Q：和短视频怀旧有何不同？** A：VR 是"走进去"的在场感与主动交互，是图片视频给不了的沉浸与参与。
- **Q：怎么解决音乐版权？** A：全程原创致敬版 + 免版税环境音。
- **Q：会不会眩晕？** A：瞬移 + 舒适转向 + 暗角，且节奏舒缓、可坐姿。
- **Q：怎么盈利？** A：线下怀旧主题展览门票 + 品牌联名定制 + 数字版销售。
- **Q：一个房间会不会太单薄？** A：靠道具密度与情感仪式，而非场景大小；单关卡正是聚焦与深度的选择。
