# 《纸上花火 · Paper Fireworks》产品需求文档
### 策划课大作业 · 需求方（甲方 / Party A）

> 说明：本课大作业要求一份**作为甲方的需求文档**。甲方可对功能模块自由定制，**不考虑实现成本、经费与时间**。本文档即「我想要一个什么样的产品」。

---

## 一、项目概述

| 项 | 内容 |
|---|---|
| 产品名称 | 《纸上花火 · Paper Fireworks》 |
| 产品类型 | 古早怀旧主题 · 沉浸式 VR 体验 / 叙事探索轻游戏 |
| 目标平台 | PC VR（Meta Quest / Pico 串流为主），另出桌面体验版便于展示 |
| 体验时长 | 单次 15–25 分钟，可重复 |
| 一句话概念 | 戴上头显，回到 2005–2012 那个 QQ 空间、非主流、花火杂志的青春年代——在一间被时光封存的少女卧室里，翻动每一件旧物，唤醒一段集体记忆，完成一次对青春的温柔告别。 |

## 二、立意与情感内核（为什么做这个）

- **母题：美好转瞬即逝；每个人的青春，都值得被温柔地收藏一次。**
- 它不是一个"通关取胜"的游戏，而是一座可以**走进去的时代记忆博物馆**：用千禧年的气味、声音、字迹与光，把一代人的青春重新点亮一次，再目送它在夏天的夕阳里散场。
- 体验关键词：**怀旧、治愈、沉浸、温柔的告别**。

## 三、目标用户与使用场景

- **核心用户**：90 后 / 95 后——QQ 空间原住民、花火/飞言情读者、非主流时代的亲历者。
- **扩展用户**：Y2K / 千禧美学爱好者、情感治愈与沉浸体验玩家、文创与展览观众。
- **使用场景**：① 个人头显沉浸体验；② 线下"怀旧"主题快闪 / 展览 / 体验馆；③ 品牌联名（汽水、文具、音乐 App 等怀旧营销）。

## 四、需求功能模块（甲方提出，不限可行性）

### 4.1 场景：一间被时光封存的千禧少女卧室
高度还原 2005–2012 的细节：碎花床单、贴满海报与明星贴纸的墙、老式台式电脑（CRT 显示器 + QQ）、卡带机 / MP3、梳妆台、铁皮文具盒、毛绒玩具、星空夜光顶贴、铁丝相片墙、成摞的花火杂志、窗外是夏日傍晚的晚霞与蝉鸣、慢慢转的电风扇。

### 4.2 互动旧物（每一件 = 一段可唤醒的记忆）
| 旧物 | 交互 | 唤起的记忆 |
|---|---|---|
| 老式台式机 | 开机 → 进入 **QQ 空间**（闪图、非主流签名、背景音乐自动播放、踩空间） | 那年的网络青春 |
| 卡带机 / MP3 | 放入磁带 / 戴上耳机 → 播放那年的歌（**原创致敬版**避版权） | 一首歌一段心事 |
| 花火 / 飞言情杂志 | 抓取 → 翻页，出现古早言情插画 + 竖排金句 | 课桌下偷看的言情 |
| 同学录 | 翻开 → 手写体留言"长大想做什么 / 给十年后的你" | 毕业季 |
| 大头贴墙 | 拼贴大头贴小玩法 | 和好朋友的合照 |
| 钢笔 + 信纸 | **写一封寄不出的信**（手柄书写 / 语音），封进漂流瓶或轻轻烧掉 | 没说出口的话 |
| 拍立得相机 | 给房间拍照 → 生成"老照片"滤镜留念 | 把此刻收藏 |
| 日历 / 闹钟 | 推进"那年夏天"的时间线 | 倒数着的暑假 |

### 4.3 核心玩法
- **自由漫游探索**（第一人称 VR + 手柄交互）；
- **收集"记忆碎片"**：唤醒一件旧物得到一片记忆，集齐解锁结局；
- **写信告别**与**拍照留念**两个情感仪式；
- **无失败、无倒计时、治愈向**，节奏舒缓。

### 4.4 UI（两种模式都要）
- **Overlay（屏幕）**：系统标题、记忆收集进度、相册、设置；
- **WorldSpace（场景内）**：QQ 空间界面、杂志页、旧物上的浮动提示，都"长"在物体上。

### 4.5 音乐与音效
卡带底噪、夏日蝉鸣、电扇嗡声、机械键盘、QQ 上线 / "咳嗽"提示音、拨号上网音；一首**原创年代感主题曲**贯穿。

### 4.6 粒子与氛围
夕照里的浮尘、飘动的窗帘、夜晚的萤火 / 远处烟花、结局时房间"褪色光化"。

### 4.7 结局（收束）
集齐全部记忆后，房间在夕阳里慢慢褪色、光化、飘散——玩家完成对青春的告别，浮出落款金句。呼应母题"美好转瞬即逝"。

### 4.8 设备与技术期望（甲方只提期望，不管实现）
PC VR，手柄交互；高还原度建模与做旧材质；电影级怀旧调色；舒适不眩晕；可一键出桌面演示版与 360° 截图用于展览传播。

## 五、核心体验流程
`进入房间（黄昏）` → `自由探索 · 逐件唤醒旧物` → `集齐记忆碎片` → `写一封寄不出的信` → `拍一张留念照` → `房间褪色光化 · 告别` → `落款金句`

## 六、验收 / 效果期望（甲方眼里"做成了"长什么样）
1. **还原度**：一进房间，目标用户脱口而出"这就是我那时候的房间"。
2. **情感共鸣**：至少一件旧物能让人鼻子一酸。
3. **沉浸与舒适**：无眩晕、可久待、舍不得走。
4. **可传播**：每一帧都能截图发朋友圈；适合做成展览 / 联名。
