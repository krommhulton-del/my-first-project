# 《纸上花火 · Paper Fireworks》解决方案
### 策划课大作业 · 实现方（乙方 / Party B）

> 说明：本课要求一份**满足甲方需求的解决方案**，需对甲方提出的问题给出**解决办法**与**效果呈现的参考图片**。本文档即「我要怎么把它做出来、做出来长什么样」。

---

## 一、对甲方需求的理解（一句话）
甲方要的不是一个"游戏"，是一台**情绪时光机**——所以本方案的一切设计，都围绕一个目标：**让人一进去就想起自己的青春，并舍不得离开。** 还原度、声音、光与字迹，是这件事的命门。

## 二、设计总览（怎么解决）
| 甲方需求 | 我的解决办法 |
|---|---|
| 高还原千禧少女卧室 | 3D 建模 + PBR 做旧材质 + 海量年代道具；**电影级怀旧后处理**（暖黄调色 + 暗角 + 胶片颗粒 + 轻微泛黄）把"塑料 3D"压成"旧照片" |
| 旧物 = 记忆 | 每件旧物 = 一个**可交互体（XR 抓取/触发）+ 一段触发演出（音乐/动画/竖排文字）+ 一片记忆碎片** |
| 自由漫游 + 不眩晕 | XR Interaction Toolkit；**瞬移 + 舒适转向（snap turn）+ 暗角减晕**；无失败无倒计时 |
| 两种 UI | Overlay 放系统/进度/相册；WorldSpace 把 QQ 空间、杂志页"贴"在物体上，沉浸不出戏 |
| 怀旧音乐（避版权） | **原创"致敬版"BGM**（同年代曲风、不抄旋律）+ 真实环境音（蝉鸣/电扇/拨号/QQ 音效），彻底规避版权 |
| 情感仪式 | "写一封寄不出的信"+"拍立得留念"两个**主动情感交互**，把怀旧变成参与 |
| 治愈的告别 | 结局：房间**褪色 → 光化 → 飘散** 的粒子演出 + 落款金句，完成母题落点 |
| 可传播/展览 | 一键桌面演示版 + 360° 截图；适配快闪/展览/品牌联名 |

## 三、美术与场景方案
- **风格定位**：千禧 Y2K × 古早言情 × 非主流，三股 DNA 融合——暖黄夕照、玫红与网格、闪光与渐变、衬线竖排。
- **场景**：一间约 12㎡ 的少女卧室单场景（满足"一个关卡"），靠**道具密度**而非场景大小堆出沉浸；窗外 360° 天幕做黄昏 → 入夜的光照变化。
- **色板**：暖黄夕照 `#E8C36A` / 千禧玫红 `#D96E8C` / 回忆米白 `#E8DFD3` / 夜幕蓝 `#2C3A47` / 高光白 `#F5EBD8`，统一压旧。
- **做旧手法**：贴纸边角卷起、海报褪色、塑料反光、灰尘 AO、CRT 扫描线。

## 四、互动设计方案（逐件旧物）
| 旧物 | 交互方式（XR 手柄） | 触发演出 |
|---|---|---|
| 台式机 | 按电源键 → 屏幕亮 → 射线点 QQ 图标 | WorldSpace QQ 空间面板：闪图头像、非主流签名、自动播放空间音乐、可"踩一踩" |
| 卡带机/MP3 | 抓磁带放入 / 戴耳机 | 原创年代曲淡入 + 屏幕歌词竖排浮现 |
| 杂志 | 抓取 + 翻页（物理） | 古早言情插画 + 竖排金句逐行浮入 |
| 同学录 | 翻开 | 手写体留言渐显 + 沙沙翻页声 |
| 信纸钢笔 | 手柄书写 / 语音 → 封口 / 点燃 | 信化作光点 / 灰烬飘出窗外 + 一记柔和音效 |
| 拍立得 | 举起取景 + 按快门 | "咔嚓" + 吐出照片（带做旧滤镜）贴上相片墙 |
| 日历闹钟 | 撕日历 / 按停闹钟 | 推进时间线、光照变化 |

## 五、系统与玩法方案
- **记忆收集系统**：8 件核心旧物 = 8 片记忆；Overlay 进度条显示；集齐触发结局。
- **情感仪式系统**：写信 + 拍照，结果保存进"相册/漂流瓶"，可在结尾回看。
- **引导**：无硬性引导，用**光与声**软引导（未唤醒的旧物有微光 + 轻响）。
- **无失败设计**：纯探索治愈，照顾非玩家用户与展览观众。

## 六、叙事流程（节拍）
`黄昏入场（蝉鸣 + 暖光）` → `软引导探索，逐件唤醒，记忆闪回` → `集齐 8 片，时间推到入夜` → `写一封寄不出的信` → `拍下最后一张照片` → `房间褪色光化、旧物一件件飘散` → `黑场落款金句：「那年夏天，我们都以为来日方长。」`

## 七、UI 方案（两模式落地）
- **Overlay**：① 进入标题卡；② 顶部记忆进度（8 颗星）；③ 相册/信件回看；④ 设置（瞬移/转向/字幕）。
- **WorldSpace**：① CRT 里的 QQ 空间；② 杂志/同学录页面；③ 旧物悬浮提示。两种模式同时演示，正好满足课程「Overlay 或 WorldSpace」要求（我两个都做）。

## 八、音频方案
原创主题曲（钢琴 + 卡带底噪，年代感）+ 环境层（蝉鸣/电扇/楼下广播/拨号上网/QQ 音效）+ 交互音效（翻页、快门、写字、点燃）。**全部原创或免版税，彻底规避版权风险。**

## 九、技术方案
- 引擎：**Unity + URP**（用 URP Volume 做 Bloom / 暖色调 / 颗粒 / 暗角）。
- 交互：**XR Interaction Toolkit**（Ray + Direct Interactor）+ XR Device Simulator（无头显可演示/录屏）。
- 文字：TextMeshPro 竖排 + 中文衬线（思源宋体）。
- 资源：场景道具用建模 + 免费/自制资源；角色无强需求（第一人称只露手）。
- 输出：PC VR 包 + 桌面演示版 + 360° 截图工具。

## 十、防眩晕与体验（UX）
瞬移移动 + 舒适转向 + 移动时暗角；交互在手边、视线舒适区；无快速位移、无强闪烁；可坐可站。

## 十二、开发里程碑（形式化排期）

## 十三、风险与对策
| 风险 | 对策 |
|---|---|
| 年代音乐版权 | 全用原创致敬版 / 免版税 |
| VR 眩晕 | 瞬移 + 舒适转向 + 暗角 |
| 还原度不够"对味" | 海量真实道具参考 + 老用户测试"对不对味" |
| 体验偏静态 | 加入写信/拍照两个主动仪式提升参与感 |

## 十四、商业与展览价值
怀旧是强情绪流量；本产品天然适合**线下快闪/展览**与**品牌联名**（汽水、文具、音乐 App），每一帧可截图传播，长尾与话题性强。
