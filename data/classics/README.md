## 用它的规矩

拿到原文之前,代码里凡涉出处一律写「通行口径,出处待核」(见 `CLAUDE.md` 第八节)。
**现在这五本可以逐条挂真出处了**——但必须是**在这几个文件里搜得到原话**才挂,
搜不到的继续写「出处待核」。不许因为「手上有书了」就凭印象写书名章节。
